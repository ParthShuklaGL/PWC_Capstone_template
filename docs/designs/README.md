# Designs

These show the **design intent** for the main screens, as an admin sees them with the seeded data. They are a guide to layout and content, not a pixel specification. Your React or Angular app can look different and still meet the tickets.

**Not shown on purpose:**
- loading, empty and error states
- validation messages
- what a sales rep sees instead of an admin
- the account screens and the admin forms other than the deal form

Designing these, from the tickets and the API's behaviour, is part of the work.
