# PWC_Capstone_template

Boilerplate and planning material for the CRM capstone.

| Folder | What it is |
|---|---|
| [nimbus_crm](nimbus_crm) | .NET 10 + MySQL backend boilerplate: register / sign in / sign out (JWT, cookie, session), CSRF protection, USER and ADMIN roles, reports with CSV export, sample data, 82 tests. See its README to run it. |
| [nimbus_crm/docs](nimbus_crm/docs) | Frontend brief for students, in a [detailed](nimbus_crm/docs/boilerplate-and-frontend-tasks.detailed.md) and a [simple](nimbus_crm/docs/boilerplate-and-frontend-tasks.simple.md) version. |
| [fsd-boilerplate](fsd-boilerplate) | React + Spring Boot + MySQL full-stack sample (compiles, JWT unit tests pass; its flows have not been run end to end). |
| [plan.md](plan.md) | Step-by-step plan for completing the projects. |

Development passwords that appear in these files are published on purpose, are only used in Development, and must never be reused.
